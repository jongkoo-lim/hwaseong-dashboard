# 화성시립도서관 · 목동이음터 도서 조회 대시보드

책 제목을 여러 개 넣으면 화성시립도서관 공개 카탈로그를 조회해서 **목동이음터 소장 여부, 대출 상태, 청구기호·위치, 상호대차 가능 여부, 소장 도서관**을 한 화면에 보여 주는 로컬 대시보드입니다.

- 서버: Node.js 18 이상, 외부 패키지 없음
- 화면: HTML/CSS/바닐라 JavaScript
- 데이터: 화성시립도서관 공개 검색 페이지와 소장정보 API(사이트 내부 요청)
- 기준 도서관: **목동이음터** (`MI`)

## 실행

```bash
npm start
```

기본 주소는 `http://127.0.0.1:3000`입니다.

`PORT` 환경 변수가 이미 설정된 환경이라면 포트를 직접 지정하세요.

```bash
PORT=3000 npm start
```

포트가 사용 중이면 다른 번호를 사용할 수 있습니다.

```bash
PORT=3001 npm start
```

> `HOST=0.0.0.0`을 지정하면 같은 네트워크의 다른 기기에서도 접속할 수 있습니다. 기본값은 `127.0.0.1`이라 내 컴퓨터에서만 접속됩니다.

## 사용법

1. 책 제목을 한 줄에 한 권씩 입력합니다. 정확한 제목이 아니어도 되고, 띄어쓰기가 조금 달라도 됩니다.
2. **도서 조회**를 누릅니다. `Ctrl / ⌘ + Enter`로도 실행할 수 있습니다.
3. 결과 카드에서 상태와 소장 정보를 확인합니다.
4. 카드의 **전체 소장 정보**를 펼치면 판본별·도서관별 소장본을 모두 볼 수 있습니다.

### 검색 옵션

- **검색어당 최대**: 검색어 하나에서 가져올 작품 수 (기본 100권)
- **전체 최대**: 한 번에 표시할 전체 작품 수 (기본 300권)
- **점자·큰글자 포함**: 끄면 점자/큰글자 자료를 상태 판정에서 제외합니다.
- **작은도서관 포함**: 끄면 작은도서관 소장본을 상태 판정에서 제외합니다.
- **검색 방식**
  - `제목에 검색어 포함`(권장): 카탈로그 결과 중 제목에 입력한 단어가 포함된 자료를 우선 사용합니다.
  - `도서관 검색 결과 전체`: 제목 일치 여부와 관계없이 카탈로그가 반환한 관련 자료를 사용합니다.

### 상태 색상

| 상태 | 의미 | 판정 기준 |
| --- | --- | --- |
| 🟢 목동 비치중 | 지금 목동이음터에서 대출 가능 | 목동이음터 소장본 중 `비치중`이 하나 이상 |
| 🟡 대출중 · 타관 가능 | 목동은 모두 대출중, 다른 도서관은 비치 | 목동 소장본은 있지만 모두 대출 불가, 타관에 `비치중` 존재 |
| 🔵 타관에만 있음 | 목동 미소장, 다른 도서관은 비치 | 목동 소장본 없음, 타관에 `비치중` 존재 |
| 🔴 전체 미소장/불가 | 어디에도 바로 대출 가능한 책이 없음 | 위 조건에 모두 해당하지 않음 |

카드에는 다음 정보가 함께 표시됩니다.

- 목동이음터 청구기호와 자료실 위치
- 목동이음터 소장본별 상태, 반납 예정일, 예약 인원
- 타관 소장 도서관 목록 — 한 책에 대해 도서관마다 줄을 만들지 않고 콤마로 묶어 한 줄에 표시 (예: 화성동탄중앙도서관, 남양도서관, 태안도서관)
- `상호대차` / `대출예약` 가능 여부
- 점자·큰글자 등 자료 형식
- 원문 카탈로그 링크

### 필터와 정렬

- **상태 탭**: 🟢 / 🟡 / 🔵 / 🔴 — 전체 탭은 없습니다. 색을 한 번 누르면 해당 상태만 보고, 다시 누르면 원래 목록으로 돌아갑니다.
- **검색어 필터**: 여러 제목을 검색했을 때 특정 검색어 결과만 보기 (다시 누르면 해제)
- **정렬**: 청구기호순 고정 (KDC 숫자, 소수점까지) — 서가에서 찾기 쉽게 하기 위함입니다.
- **CSV 저장**: 현재 필터에 보이는 결과를 엑셀에서 바로 열 수 있는 UTF-8 CSV로 저장

### 카드 표시

- 카드 내용은 간략하게 표시합니다: 제목, 저자·연도, **청구기호**(크게), 목동이음터 비치/대출중, 타관 도서관 목록(콤마), 상호대차·대출예약 여부, 카탈로그 링크.
- 청구기호는 책을 바로 찾아가야 하는 정보라 카드 상단에 크게 표시합니다. 파란/노란/빨간 상태일 때(목동 미소장·대출중)는 빌릴 수 있는 타관 소장본의 청구기호와 도서관·위치가 표시됩니다.
- 카드의 청구기호는 대표 소장본 1권 기준입니다. 목동에 여러 권이 있으면 나머지 권수는 `외 N권`으로 안내하고, **소장 정보 보기**를 펼치면 도서관별·청구기호별 소장본을 모두 볼 수 있습니다.
- 상태가 바뀐 이유를 길게 설명하는 문장, 판본/점자·큰글자/제외권수 같은 보조 설명은 카드에 표시하지 않습니다. 상세 정보는 **소장 정보 보기**에 있습니다.

### 사진에서 책 제목 뽑기

**검색 맨 위의 사진으로 검색하기**에 독서플랜 스크린샷 같은 사진을 넣으면 OCR로 책 제목만 뽑아 검색창에 넣을 수 있습니다. 사진은 웹 이미지 추가처럼 직관적으로 넣습니다.

- **클릭/사진 선택하기 버튼**, **드래그**, **붙여넣기(Ctrl+V)** 중 하나로 바로 들어갑니다.
- 들어가면 **미리보기 사진, 파일 이름·크기·해상도, ✔ 사진이 들어왔습니다** 표시를 바로 볼 수 있습니다. 바꾸려면 다른 사진으로 바꾸기, 지우려면 사진 지우기를 누릅니다.
- OCR이 끝나면 **뽑은 제목을 검색창에 자동으로 넣고** 검색창으로 이동·강조합니다. 아래 **도서 조회**를 누르면 됩니다.
- 제목이 안 뽑히면 **읽은 글자 원문**을 펼쳐 직접 고친 뒤 다시 뽑을 수 있습니다.
- 인식 방식: 사진을 확대하고, 사진마다 자동 임계값(Otsu)으로 글자만 남긴 뒤 OCR을 돌립니다. 목록이 적으면 흩어진 글자 모드와 사진 세로 잘라 읽기로 보완합니다.
- 딱지 판정: 줄의 실제 높이 범위에서 HSV 색상으로 빨강(첫째)·초록(둘째)을 셉니다. 흩어진 색 점은 무시합니다.
- 틀린 딱지는 뱃지를 눌러 바꿀 수 있고, 빠진 제목은 목록 아래 입력란에 직접 추가할 수 있습니다.

- `JK2 그림책/국내창작` 같은 카테고리, `(숫자)`, `원서` 꼬리표는 제목에서 제외합니다.
- 오른쪽 빨간 딱지(첫째)·초록 딱지(둘째)를 이미지 색상으로 감지합니다. **빨강과 초록이 둘 다 붙은 책은 자동으로 체크를 해제해서 검색하지 않습니다.** 첫째만/둘째만/딱지 없는 책은 검색에 넣습니다.
- 뽑은 제목은 목록에서 직접 고칠 수 있습니다. `체크한 제목만 검색창에 넣기`는 추가, `바로 조회`는 넣고 바로 검색합니다.
- 처음 사용할 때 OCR 라이브러리(Tesseract.js, CDN)를 불러와서 시간이 걸릴 수 있습니다. 인터넷 연결이 필요합니다.

### 표지 이미지 추가

- 책 카드의 표지 위에 마우스를 올리면 **🖼 이미지 추가** 버튼이 표시됩니다.
- 이미지 파일(10MB 이하)을 선택하거나 드래그하거나, 이미지 URL을 입력해서 표지로 적용할 수 있습니다.
- 직접 추가한 표지는 이 브라우저에만 저장됩니다. 다음에 같은 책을 조회하면 다시 표시됩니다.
- 표지를 바꾸려면 다시 **🖼 이미지 추가**를 눌러 새 이미지를 적용하고, 되돌리려면 **직접 추가한 표지 제거**를 누르세요.

## 동작 방식

브라우저에서 화성시립도서관 사이트를 직접 호출하면 CORS로 막히기 때문에, 로컬 Node 서버가 대신 요청합니다.

```text
브라우저
  │  POST /api/search  (NDJSON 스트리밍)
  ▼
로컬 Node 서버
  │  GET  검색 결과 페이지
  │  POST 소장정보 요청 (speciesKey)
  ▼
화성시립도서관 공개 카탈로그
```

### 서버

- `GET /api/health` — 서버 상태 확인
- `POST /api/search` — 검색 실행, `application/x-ndjson`으로 진행 상황을 한 줄씩 전송
- `GET /` — 대시보드 정적 파일

검색 요청 본문 예시:

```json
{
  "queries": ["채식주의자", "불편한 편의점"],
  "limitPerQuery": 100,
  "maxTotalWorks": 300,
  "maxEditions": 10,
  "mode": "title",
  "fresh": false
}
```

스트리밍 이벤트 종류:

- `start`, `query-start`, `query`, `plan`
- `book` — 소장 정보까지 조회된 작품 하나
- `progress`, `done`, `error`

작품은 `제목 + 권차 + 저자` 기준으로 묶고, 같은 작품의 여러 ISBN/판본은 하나의 카드로 합칩니다. 검색 결과의 물리적 소장본 수와 작품 수가 다르기 때문에 사이트의 전체 건수와 카드 수는 일치하지 않을 수 있습니다.

### 파일 구조

```text
.
├── package.json
├── server.js              # 정적 파일 서버 + 검색 API
├── src/
│   ├── catalog.js         # 검색·파싱·작품 그룹화·소장 상태 판정·캐시
│   └── libraries.js       # 화성시립도서관 지점 코드/이름/작은도서관 여부
└── public/
    ├── index.html         # 대시보드 마크업
    ├── styles.css         # 반응형 스타일
    └── app.js             # 검색 실행, 상태 필터, 정렬, 카드 렌더링, CSV
```

### 캐시와 속도

- 검색 결과와 소장 정보는 메모리에 캐시됩니다. 같은 책을 다시 조회하면 빨라집니다.
- **새로고침**은 캐시를 무시하고 다시 가져옵니다.
- 소장 정보는 동시에 4개씩 조회하고, 일시적인 오류는 재시도합니다.
- 결과가 많은 제목은 검색어당 상한과 전체 상한으로 잘라 냅니다. 이때 경고가 표시됩니다.

## 참고 및 한계

- 대출 상태는 **조회 시점의 카탈로그 값**입니다. 실제 대출 가능 여부는 도서관 운영 상황에 따라 달라질 수 있습니다.
- 카탈로그 페이지 구조가 바뀌면 파서를 수정해야 할 수 있습니다.
- 사이트 전체 건수는 작품 수가 아니라 소장본/검색 결과 건수입니다.
- `분실`, `폐기`, `정리중`, `예약중`, `상호대차중` 등은 대출 가능으로 보지 않습니다.
- 상호대차 가능 표시는 해당 타관 소장본에 카탈로그의 `상호대차` 서비스 링크가 있을 때만 켜집니다. 타관에 책이 있어도 상호대차가 불가능한 경우가 있습니다.
- 공공데이터 API 키는 사용하지 않습니다. 요청한 키가 활성화되어 있지 않아, 별도 키 없이 동작하는 공개 카탈로그 조회 방식을 사용했습니다. 키 값은 코드에 저장되어 있지 않습니다.

## 문제 해결

**`EADDRINUSE`가 표시됩니다.**
다른 포트를 지정합니다.

```bash
PORT=3001 npm start
```

**조회 결과가 0권입니다.**
제목 일부만 다시 입력하거나, 검색 옵션에서 `도서관 검색 결과 전체`를 선택해 보세요. 도서관 사이트가 일시적으로 느리거나 응답하지 않을 수도 있습니다.

**결과가 너무 많습니다.**
검색어를 더 구체적으로 입력하거나 `검색어당 최대`를 낮추세요.

**점자·큰글자 자료 때문에 초록으로 표시됩니다.**
검색 옵션에서 `점자·큰글자 포함`을 끄면 일반 자료만 기준으로 다시 판정합니다.
